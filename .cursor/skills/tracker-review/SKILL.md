# Проверка задачи

Ничего не коммитить, не пушить и не открывать pull request. Bugbot не вызывать: не писать в PR `bugbot run`, `cursor review` и не запускать навык review-bugbot. Навык tracker-commit-pr сам не вызывать.

## 1. ТЗ и критерии приемки

Найди постановку задачи и список критериев приемки. Не выдумывай критерии, которых нет в задаче.

По каждому критерию запиши: сделано, с файлом или экраном; не сделано, и чего не хватает; нельзя проверить по коду, и что для этого нужно. Отметь, где реализация противоречит ТЗ.

## 2. Код-ревью

Прочитай diff текущей ветки.

Фронтенд: корректность сценария, регрессии, краевые случаи, соответствие макету и стиль кодовой базы. Проверь, что весь функционал из задачи работает относительно бэкенда: нужные запросы уходят, ответы и ошибки разбираются, заявленный сценарий не остаётся только вёрсткой.

Бэкенд: качество кода, соответствие ТЗ, архитектуре и контракту API, регрессии и краевые случаи. Браузер не открывай.

Для каждого замечания укажи файл, место и что сломается. Замечания про стиль без последствия для поведения не включай.

## 3. Брауз
Прочитай diffфронтенд

Для бэкенда этот шаг пропусти.

Для фронтенда проверь изменённый сценарий через уже подключённый Playwright MCP (user-playwright). Сначала прочитай схему инструментов, потом открой страницу и пройди каждый заявленный в задаче сценарий. Данные бери из задачи, окружения или тестовых хелперов проекта. Сверь экран с макетом и убедись, что функционал работает вместе с бэкендом.

Не устанавливай Playwright и не запускай npx playwright install или npm install playwright. Если данных для входа или макета нет — напиши об этом в отчет и не выдумывай учётные данные.

## Отчет

- Задача: номер и название
- ТЗ: по каждому критерию — сделано, не сделано или не проверено
- Код-ревью: замечания или «блокирующих замечаний нет»
- Браузер: совпало с макетом, список расхождений, «не фронтенд» или «макет не приложен»
- Итог: можно сдавать или сначала исправить список ниже

## Дальше

Отчет отправь и остановись. Спроси: «Проверка закончена. Продолжить навыком tracker-commit-pr?»

Не вызывай tracker-commit-pr, пока пользователь явно не согласится. Коммит и пуш не делай.
